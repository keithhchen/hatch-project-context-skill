# Creator-first 的品牌与分发

## Creator 的 identity 在先

消费者购买的是某位 Creator 的产品，而不是 Hatch 平台里一个无差别的 Agent。Creator 应当是前台体验的主角；Hatch 的角色是标准化后台的创建、运行、支付、安全和履约能力。

Hatch 不需要优先建立强势的 consumer brand。它首先需要获得 Creator 的信任，让 Creator 愿意把自己的身份、方法和粉丝关系交给平台承载。

Creator 分发的不是一个普通 Hatch 工具链接，而是一个符合自己风格的完整产品体验。Hatch 可以作为基础设施或可信背书被看见，但不能压过 Creator 品牌。

## 用户从哪里来

典型消费者路径不是先访问 Hatch Marketplace，而是：

```text
Creator 的 YouTube / 社交主页 / 课程 / 社群
→ Creator 自己的 Agent 产品页面
→ 查看具体价值与交付物
→ 购买或订阅
→ 使用 Agent 完成工作
→ 得到可交付成果
```

Hatch 的获客和分发应借助 Creator 已经建立的信任与受众，而不是同时承担从零建立消费者 Marketplace 的任务。

## 产品设计含义

- Creator profile、头像、主题、说明、示例成果和产品视觉都属于产品本体，不只是宣传素材。
- 前台应围绕 Creator/IP 组织，而不是围绕一个“Apps Gallery”组织。
- 后台能力可以统一，消费者体验应允许 Creator 呈现自己的风格和价值主张。
- 同一个 Hatch 账号可以承载购买的 Agent、自己创建的 Agent，以及自己作为 Creator 发布的 Agent。

## 尚未包含的结论

本文件不确定 Hatch 是否必须完全 white-label，也不确定 `Powered by Hatch` 的最终可见程度。这属于后续品牌设计决策。
