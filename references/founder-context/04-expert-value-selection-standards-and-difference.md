# 专家的价值在选择、标准与差异

## 专家不只是“知道更多”

公开知识越来越容易被通用模型读取和重组。专家真正稀缺的价值往往是：

- 选择什么；
- 给不同因素多大权重；
- 反复强调哪些重点；
- 删除什么、留下什么；
- 在边界和例外中如何判断；
- 什么结果符合自己愿意署名的标准。

Keith 用教育场景解释过这个问题：学科知识和考试标准可能都是公开的，但学生仍然愿意购买某位老师的课程，因为这位老师划的重点不同。强调什么，本身就是经过实践形成的判断。

## 通用模型为什么不够

通用模型经常追求覆盖全面，因此容易给出“太满”的回答。专家价值可能恰好存在于被忽视的重点、清晰的取舍和有意识的留白中。

因此，Creator Agent 的目标不是堆积更多知识，而是稳定复现 Creator 的选择、权重、标准和边界。

## “优于通用模型”是什么意思

这里的“优于”是实用主义判断，不是要求 Creator Agent 在所有问题上普世地胜过通用模型。

股票分析可以有不同策略，健身计划可以有不同流派，内容创作可以有不同审美。Hatch 需要证明的是：

1. Creator 的差异能够被稳定体现；
2. Agent 能按这套差异完成具体工作；
3. 交付物达到 Creator 愿意署名的标准；
4. 用户愿意为这种差异和结果付费。

## 产品与 Eval 的含义

质量评估不能只检查事实正确或格式完整，还要检查：

- 是否抓住了 Creator 会强调的重点；
- 是否做出了符合其风格的取舍；
- 是否避免了 Creator 会删除的内容；
- 是否在关键边界上做出了同类判断；
- 最终产物是否可直接使用、发布或交付。
